# Ruang Kendali

Reskin gelap template open source AdminLTE 3. Kode dasarnya milik AdminLTE dan berlisensi MIT.

**Demo:** https://portofolio-jauza-fawaid.netlify.app/ADMIN-DASHBOARD/

![Tampilan Ruang Kendali](docs/tampilan.jpg)

## Tentang

Berdasarkan [AdminLTE 3](https://github.com/ColorlibHQ/AdminLTE) (lisensi MIT). Lapisan tema ada di folder `atelier`.

## Menjalankan

Buka `index.html`.
